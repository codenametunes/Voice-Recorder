# Voice Recorder

A simple tool to record your voice using 8-bit PCM audio.

Program is built in C# NET 8.0.

## Features

- **Record** your voice
- **Playback** recordings
- **Stop** recording or playback

## Settings

### Sample Rate (kHz)
Choose the recording frequency.

### Audio Format
- **Unsigned 8-bit** (recommended)  
- **Signed 8-bit** (currently distorted)

### Microphone Input
Select your input device.
